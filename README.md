Student Grade Management System

About This Project

This is my Project 1 for the CMSC 2413 Visual Programming class. I built a simple Student Grade Management System using C# and Windows Forms.

The main purpose of this application is to manage student information and calculate their grades.

Features

The application allows users to:

Add students with their ID, name, and subject scores.

Search for a student using their Student ID.

Delete students from the list.

Automatically calculate the average grade.

Display whether a student passes or fails.

View student records in a table.

Programming Concepts

I used several concepts that we learned in class:

List: To store student records.

Array: To store scores for different subjects.

Dictionary: To search for students by ID.

Struct: To organize student information.

Enum: To represent Pass and Fail results.

How to Run

Open StudentGradeManager.slnx in Visual Studio.

Build the project.

Press F5 to run the application.
